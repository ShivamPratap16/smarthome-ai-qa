How this is tested

The assistant answers questions about three fictional products (Aero ceiling fan, Lock S1 door lock, Pure RO water purifier) using their manuals and a device API. The quality system around it is the real product.

What happens on every pull request

  1. Lint & unit tests run with recorded LLM responses (“cassettes”), so CI needs no API key and gives the same answer every time.
  2. All suites run and each writes reports/<suite>/latest.json.
  3. The quality gate checks hard thresholds and compares with the last accepted baseline. If the bot got worse, the PR is blocked.
  4. On merge to main this dashboard is rebuilt and published to GitHub Pages.
